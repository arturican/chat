# CODEX CONTINUE PROMPT

Продолжай разработку PulseChat по текущему состоянию репозитория.

Правила:

- сначала определи, какой phase активен сейчас;
- не ломай уже созданную структуру;
- соблюдай `AGENTS.md`;
- не добавляй случайные библиотеки;
- не перепрыгивай через этапы;
- каждый шаг доводи до рабочего состояния;
- после каждого завершенного шага делай отдельный git commit;
- push делай только по явному запросу пользователя.

Текущая логика работы:

1. Проведи короткий аудит измененных и существующих файлов.
2. Назови один ближайший маленький шаг.
3. Реализуй только его.
4. Проверь локально через релевантные команды.
5. Перечисли файлы, которые изменил.
6. Сделай commit для этого шага.
7. Коротко назови следующий маленький шаг.
