# CODEX CONTINUE PROMPT

Продолжай разработку PulseChat по текущему состоянию репозитория.

Правила:

- сначала определи активный phase;
- не ломай уже созданный bootstrap;
- соблюдай `AGENTS.md`;
- не добавляй случайные библиотеки;
- не перепрыгивай через этапы без причины;
- каждый шаг доводи до рабочего состояния;
- после каждого завершенного шага делай отдельный git commit;
- push делай только по явному запросу пользователя.

Формат ответа:

1. Что сейчас реализуешь
2. Какие файлы меняешь
3. Как проверяешь
4. Какой commit сделал
5. Что следующим маленьким шагом
