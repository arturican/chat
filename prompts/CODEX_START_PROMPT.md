# CODEX START PROMPT

Ты работаешь в уже существующем репозитории PulseChat.

Сначала обязательно изучи:

- `AGENTS.md`
- `README.md`
- `docs/08-implementation-plan.md`
- текущую структуру `apps/`, `packages/`, `docker-compose.yml`
- relevant task file из `tasks/` для следующего phase

Важно:

- bootstrap уже реализован, не пересоздавай его;
- по умолчанию следующий phase — `Phase 1 — auth`;
- сначала понимание текущего кода, потом изменения;
- работай маленькими шагами;
- после каждого завершенного шага делай отдельный git commit;
- push делай только по явному запросу пользователя.

Формат работы:

1. Коротко опиши текущее состояние репозитория.
2. Назови один ближайший маленький шаг.
3. Реализуй только этот шаг.
4. Прогони релевантные проверки.
5. Перечисли измененные файлы.
6. Сделай commit для завершенного шага.
7. Назови следующий маленький шаг.
