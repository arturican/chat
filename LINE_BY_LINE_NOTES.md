# Infra And Config Line-By-Line Notes

Этот файл объясняет построчно инфраструктурные и корневые конфиги проекта.

## `docker-compose.yml`

- `1`: Даём compose-проекту явное имя, чтобы локальные контейнеры и volume не конфликтовали со старыми проектами в этой папке.
- `2`: Пустая строка отделяет имя проекта от списка сервисов.
- `3`: Начинаем описание сервисов compose.
- `4`: Объявляем сервис `postgres`.
- `5`: Берём лёгкий образ PostgreSQL 16 на Alpine.
- `6`: Просим Docker перезапускать контейнер, если он упал или машина перезагрузилась.
- `7`: Начинаем блок env-переменных контейнера.
- `8`: Имя базы, которую Postgres создаст при первом старте пустого volume.
- `9`: Имя пользователя базы.
- `10`: Пароль этого пользователя.
- `11`: Начинаем список проброса портов.
- `12`: Пробрасываем порт контейнера `5432` на локальный `5432`.
- `13`: Начинаем список volume.
- `14`: Подключаем именованный volume для постоянного хранения данных БД.
- `15`: Закрываем описание сервиса `postgres`.
- `16`: Пустая строка перед описанием volume.
- `17`: Объявляем именованный volume `postgres_data`.
